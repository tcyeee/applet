# Applet

AI-Native Desktop Runtime — 详见 [IDEA.md](./IDEA.md) 与 [TODO.md](./TODO.md)。

技术栈：Tauri 2 + React + TypeScript + Vite。

## 开发

```bash
pnpm install
pnpm tauri dev
```

## 构建

```bash
pnpm tauri build
```

## Recommended IDE Setup
